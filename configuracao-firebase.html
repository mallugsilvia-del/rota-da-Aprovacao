Como conectar o Rota da Aprovação ao Firebase

Configure o banco uma única vez e publique as Cloud Functions de login por nickname. Depois os alunos poderão entrar com apelido e senha, mantendo o histórico; os administradores continuam usando o e-mail.

  1. Crie o projeto.Acesse o Console do Firebase, crie um projeto e adicione um aplicativo do tipo Web.
  2. Ative o Firestore.Abra “Firestore Database”, crie o banco em modo de produção e escolha uma região.
  3. Ative o login.Em “Authentication → Sign-in method”, habilite “E-mail/senha”. Se desejar, habilite também o Google.
  4. Autorize o domínio.Em “Authentication → Settings → Authorized domains”, inclua o domínio publicado, como usuario.github.io.
  5. Configure o site.Copie o objeto firebaseConfig do Console e substitua os valores no arquivo firebase-config.js.
  6. Publique as regras.Copie todo o conteúdo de firestore.rules para “Firestore → Regras” e clique em publicar.
  7. Ative o login por nickname.Cloud Functions exigem o plano Blaze no Firebase e uma publicação inicial pelo terminal com Node.js e Firebase CLI. Abra o arquivo CONFIGURAR_LOGIN_NICKNAME.txt que acompanha o projeto: ele traz os comandos completos.
  8. Autorize seu administrador.Crie primeiro a conta no Authentication, copie o UID exibido e, no Firestore, crie a coleção admins com um documento cujo ID seja exatamente esse UID. Adicione o campo ativo com valor booleano true.
  9. Abra o painel Admin.Entre com a conta autorizada. No painel Admin, use “Carregar banco completo do projeto” e depois “Importar JSON no Firestore”.

Onde o site pode ser publicado?

O site continua estático e pode ficar no Firebase Hosting, GitHub Pages ou qualquer hospedagem de HTML/CSS/JS. Somente a implantação inicial das Cloud Functions exige Node.js e Firebase CLI no computador do responsável. Alunos usam normalmente o site no navegador.

Estrutura de cada questão

O banco guarda vestibular, ano, número, matéria, tema, dificuldade, enunciado, alternativas, resposta, dica, etapas da resolução, explicação final, recomendação, fonte, imagem original e estado de publicação.

Quando o login por nickname não funcionar

Confirme que publicou as funções loginComNickname, verificarNickname e reservarNickname. Também é preciso publicar o arquivo firestore.rules desta versão. A coleção admins/{UID} continua exclusiva do administrador.
